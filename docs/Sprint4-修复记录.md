# Sprint 4 P0 修复记录：裁切结果不更新

- 日期：2026-10-24
- 基线：`c1cde4b`（Sprint 3）
- 触发反馈：手动四角框正确，但“处理结果”仍显示完整桌面照。
- 目标：裁切完成后，界面必须显示新的裁切文件，不能显示旧图/旧缓存。

---

## 1. 根因

确认了两个问题：

1. **处理结果路径复用**
   - `SessionStore.saveProcessed` 固定写到 `processed/<pageId>.jpg`；
   - 每次重新裁剪/重处理都覆盖同一路径；
   - Flutter `Image.file` 的 `ImageCache` 按路径缓存，因此可能继续显示覆盖前的旧图。

2. **旧结果文件无人清理**
   - 手动四角/候选切换会先把 `processedPath` 置空；
   - 新结果写完后，控制器已无法从当前页面拿到旧路径，旧 JPEG 留在磁盘。

引擎裁切本身是正常的：设备端把页面四角改成 `[(0.1,0.1)…(0.9,0.9)]` 后，输出
`1722×2313`，不再是原图比例。

---

## 2. 修复

- `SessionStore.saveProcessed` 改为版本化文件名：
  `processed/<pageId>_<microsecondsSinceEpoch>.<ext>`
- 控制器在成功复制新结果后删除旧 `processedPath`；
- 手动四角 / 候选切换 / 整图 2% 切换时主动清理旧文件；
- `PagePreview`、页面网格、缩略图的 `Image.file` 增加基于路径的 `ValueKey`；
- 保留“原图始终不动”的约束；只有派生结果被替换。
