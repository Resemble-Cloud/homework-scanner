## 1. 用户反馈与当前判断

用户截图：

1. 四角编辑器里的黄色框正确框住了中央纸面；
2. 应用后状态显示“已完成 / 手动四角”，但“处理结果”仍是完整桌面照片（桌面、周围笔记本都还在）。

这是 Sprint 3 之后的**最高优先级 bug**，比继续调检测、继续加候选更重要。

### 首要怀疑：不是裁切算法错了，是 UI 显示了旧缓存

当前实现：

- 处理结果固定写到 `processed/<pageId>.jpg`；
- 每次重裁/重处理都**覆盖同一个路径**；
- `Image.file` 没有 cache-busting key，Flutter 的 `ImageCache` 以路径为 key，可能继续显示旧图。

所以可能出现：

- 磁盘上的新 JPEG 已经是裁好的；
- 页面详情仍显示覆盖前的旧图（整图）。

Sprint 4 第一步必须先验证：

1. 手动四角应用后，从设备拉 `processed/<pageId>.jpg`；
2. 看实际文件的尺寸/内容是否已经是纸面；
3. 对比 `session.json` 里的 `quad`、`processedPath`、`processedAt`；
4. 若文件正确而 UI 错，修缓存/路径；若文件也错，修四角传递链。

**不要先调检测参数。**

## 2. Sprint 4 范围

### 必做（P0）

1. **修复最终图不更新**
   - 处理结果文件名改为唯一版本，例如：
     `processed/<pageId>_<processedAtTimestamp>.jpg`；
   - 新文件写成功后再删除旧文件；
   - 页面 JSON 记录新路径；
   - UI 用新路径 + `ValueKey`，或显式驱逐旧 `ImageCache`，确保立即刷新。
   - 验收：同一页连续手动裁切 3 次，每次都显示当次结果，重启 App 后仍一致。

2. **确认手动四角端到端生效**
   - 检查编辑器返回的四角是否被原样传给引擎；
   - 检查 `setManualQuad` 后 `quadSource=manual`、`quad` 持久化、原生 `scanImage` 的 `quad` 与页面记录一致；
   - 增加测试：用固定四角处理后，输出宽高比应接近该四角，而不是原图比例。

3. **预览只认真实处理文件**
   - 页面网格和详情统一取 `processedPath`；
   - 处理中显示原图+进度可以保留，但完成后必须切到新结果；
   - 不让“旧结果/旧缓存”冒充当前结果。

### 简化（P1）

用户明确说“功能不用很复杂，能实现扫描即可”。Sprint 4 要删掉/收起复杂度：

- 详情页保留主操作：**重新裁剪 / 重拍 / 删除 / 导出**；
- “检测框 / 纸面外框 / 整图 2%”候选卡片改为：
  - 默认隐藏；
  - 只在“建议检查”时提供一个“裁切方式”入口；
  - 不要在普通页面暴露技术指标。
- “去阴影”从详情页主区域收起：
  - 默认自动开启即可；
  - 需要时放到二级“更多”里，不占主流程。
- 去掉详情页里的检测分数、coverage、引擎入口等调试信息；这些留在日志/验收报告，不放进用户界面。
- 首页保持：大按钮“扫描”、页面网格、PDF 导出，足够。

### 已有能力保留，不重做

- 连续拍照、后台串行、缩略图状态；
- 多页排序、重拍、删除、会话恢复；
- PDF 直接嵌入 JPEG、A4 选项、分享；
- FairScan 引擎和现有纸面外框候选。

## 4. 验收标准

### 必须通过

1. 相机拍/相册导入一页摊开的笔记本；
2. 自动裁切或手动四角后，详情页显示：
   - 纸面主体；
   - 不再显示完整桌面；
   - 图像内容与磁盘 `processed` 文件一致。
3. 同一页连续重新裁剪 2 次，第二次立即显示新结果，不出现旧图；
4. 强杀/重启后，打开该页仍显示裁切后的结果；
5. 导出 PDF 中该页是裁切后的内容，顺序/方向正确；
6. 8 页会话仍可完成：拍/导 → 处理 → 排序/重拍 1 页 → PDF；
7. `flutter analyze`、`flutter test`、原生单测、arm64 Release 全绿。

### 真机

- 必须在实体手机上重复以上第 1–5 项；
- 记录型号、Android 版本、截图、PDF 路径；
- 没有实体机时只能写“阻塞”，不能写“通过”。

## 5. 测试计划

新增/加强：

- **文件级测试**：手动四角处理后读取输出 JPEG 的宽高，断言不是原图尺寸；
- **路径版本测试**：同一页重处理两次，`processedPath` 不同；
- **缓存回归**：widget test 里更新 `processedPath`，断言 Image widget 使用新路径/新 key；
- **会话恢复**：重启后读取新结果；
- **PDF 回归**：裁切页导出后 PDF 尺寸/页数/顺序不变；
- **设备端**：手动四角后截图 + 拉文件对比，避免只看 UI 截图。
